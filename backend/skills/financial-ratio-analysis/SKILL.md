# 财务比率分析技能

## 适用场景
用户询问公司财务指标、盈利能力、偿债能力、运营效率时启用此技能。

## 分析维度

1. **盈利能力**
   - ROE（净资产收益率）
   - ROA（总资产收益率）
   - 毛利率、净利率、营业利润率
2. **偿债能力**
   - 资产负债率
   - 流动比率、速动比率
   - 利息保障倍数
3. **运营效率**
   - 存货周转率、应收账款周转率、总资产周转率
4. **增长能力**
   - 营收增长率、净利润增长率

## 输出要求
- 用 Markdown 表格呈现各比率（行=指标，列=年份）
- 若文档中有行业均值，给出对比
- 末尾给出 2-3 条风险提示
- 引用具体数据来源（年份 + 文档章节）
