# 研报摘要技能

## 适用场景
用户上传长篇研究报告，或要求总结一篇研报、给出研报核心观点时启用。

## 输出结构

### 1. 公司一句话定位
用一句话概括公司主营业务和行业地位。

### 2. 投资逻辑（3 条以内）
每条一句话，给出"驱动因素 + 预期催化 + 时间窗口"。

### 3. 关键财务数据
用 Markdown 表格呈现：
- 营收 / 净利润（近 3 年）
- 增速、毛利率、净利率
- 资产负债率

### 4. 风险提示
列出 3-5 条核心风险，每条一句话。

### 5. 评级与目标价（若有）
报告中的评级、目标价、对应空间。

## 输出要求
- 总长度控制在 500 字以内
- 多用 bullet 而非段落
- 引用关键数据时标注页码或段落
