# 估值汇总技能

## 适用场景
用户询问目标价、估值倍数、买卖建议、可比公司估值时启用。

## 分析要点

1. **当前估值倍数**
   - PE（TTM / 动态 / 静态）
   - PB
   - EV/EBITDA
   - PEG（若有增速数据）
2. **历史分位**
   - 当前倍数处于近 3/5 年历史分位的什么位置
3. **DCF 估值**（若文档中有）
   - 核心假设（WACC、永续增长率）
   - 敏感性分析
   - 给出目标价区间
4. **可比公司**
   - 行业内可比公司平均估值
   - 相对溢价/折价说明

## 输出要求
- 用表格展示估值倍数对比
- 给出投资评级建议（仅基于文档数据，不臆断）
- 标注每个数据的来源
