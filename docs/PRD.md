# 金融投研知识库问答Agent - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位
**FinanceWiki Agent** - 一个面向金融投研场景的轻量级智能知识库问答系统，通过三路召回检索（向量语义 + 关键词 + 知识图谱）实现精准检索，支持多轮对话记忆，帮助用户高效获取和分析金融信息。

### 1.2 目标用户
- 金融分析师/研究员
- 投资经理/基金经理
- 金融科技开发者
- 面试展示/技术学习者

### 1.3 核心价值
1. **智能问答**: 基于文档内容的精准问答
2. **三路检索**: 向量语义 + 关键词 + 知识图谱，全面覆盖
3. **多轮对话**: 支持上下文记忆，深入探讨复杂问题
4. **灵活扩展**: 支持多种大模型切换

## 4. 用户流程

### 4.1 文档导入流程
```
1. 用户进入文档管理页面
2. 点击"上传文档"按钮
3. 选择本地文件 (PDF/Word/MD/TXT)
4. 系统自动解析文档内容
5. 系统生成向量索引和BM25索引
6. 系统提取实体和关系，构建知识图谱
7. 用户可以在知识图谱页面查看提取结果
```

### 4.2 问答对话流程
```
1. 用户进入对话页面
2. 输入问题或选择历史对话
3. 系统进行查询改写（生成3个查询变体）
4. 三路并行检索：
   - 向量检索（语义匹配）
   - 关键词检索（BM25）
   - 知识图谱检索（实体扩展）
5. RRF融合三路检索结果
6. 重排序获取最相关片段
7. 结合记忆系统生成上下文
8. LLM生成回答（流式输出）
9. 保存到对话历史
10. 更新记忆系统
```

### 4.3 知识图谱浏览流程
```
1. 用户进入知识图谱页面
2. 查看图谱可视化
3. 搜索实体或关系
4. 点击实体查看详情
5. 查看实体关联的文档
```

## 7. API接口

```
POST   /api/documents/upload          # 上传文档

GET    /api/documents/{id}            # 获取文档详情
DELETE /api/documents/{id}            # 删除文档及关联数据
GET    /api/documents/{id}/entities   # 获取文档实体
GET    /api/documents/{id}/relations  # 获取文档关系
```

### 7.2 知识图谱
```
GET    /api/knowledge-graph           # 获取图谱概览
GET    /api/knowledge-graph/entity/{name}  # 获取实体详情
GET    /api/knowledge-graph/search    # 搜索实体和关系
GET    /api/knowledge-graph/stats     # 获取图谱统计
```

### 7.3 对话管理
```
POST   /api/chat                      # 发送消息
GET    /api/chat/history              # 获取对话历史

POST   /api/chat/sessions             # 创建新会话

```

### 7.4 模型管理
```
GET    /api/models                    # 获取模型列表
```

## 8. 技术约束

### 8.1 技术栈
- **后端**: Python 3.10+, FastAPI
- **前端**: Vue3 + Element Plus + Pinia
- **数据库**: SQLite (元数据) + Qdrant (向量) + NetworkX (知识图谱)
- **缓存/队列**: Redis (缓存/会话/异步队列)
- **嵌入模型**: 国产embedding API (智谱/DeepSeek)
- **大模型**: 智谱GLM-4, DeepSeek, Kimi, MiniMax

### 8.2 部署要求
- **操作系统**: Windows 10+, macOS, Linux
- **Python**: 3.10+
- **Node.js**: 16+ (仅开发时需要)
- **Docker**: 20.10+ (推荐，用于Qdrant和Redis)
- **内存**: 4GB+ (推荐8GB)
- **磁盘**: 2GB+ (含依赖)

### 8.3 依赖服务
- 国产大模型API (需用户自行配置API Key)
- Qdrant向量数据库 (Docker部署)
- Redis缓存服务 (Docker部署)
- SQLite本地存储
